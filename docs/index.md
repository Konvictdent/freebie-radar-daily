## 它解决什么问题

自己追福利最烦的不是找不到，而是**信息太杂**：付费好价混在白嫖里、拼车帖混在新闻里、同一批内容被十几个源重复推送。

资源雷达把这条链路拆成四步，每步都能单独调：

1. **采集** —— 多路内置采集器 + 自定义 RSS + 登录态回环助手，统一入库去重
2. **初筛** —— 关键词规则 + 统一屏蔽词，明显不想要的在送 AI 之前就丢掉
3. **定级** —— AI 输出 `keep` / 形态 / 领域 / 获取方式 / 质量分 / 中文理由，规则只做兜底
4. **分发** —— 网页按频道呈现，Telegram / Webhook 按路由推送
